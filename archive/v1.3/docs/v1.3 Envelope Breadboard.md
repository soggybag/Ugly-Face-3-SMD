# UF3 v1.3 envelope: breadboard build and test (unit 1)

Goal: hear the new envelope (`v1.3 Envelope.md`) on a built v1.1 board before ordering v1.3. Refs match the v1.3 schematic.

## Parts (through-hole)

| Ref | Part | Note |
|---|---|---|
| U5 | **LM358** DIP-8 | (any dual op-amp that works from 9 V single supply; LM358 is what v1.3 uses) |
| Q1 | **2N3904** | flat face toward you, legs down: **E B C** left to right |
| D5 | 1N4148 | band = cathode |
| RV1 | **A10k** pot (B10k is fine for the test) | ENVELOPE |
| RV6 | 500k trimmer or pot (or 220k fixed to start) | DECAY |
| C20 | 33n (also have 22n and 68n to try) | tilt |
| C21 | 1µ (film or ceramic) | hold cap |
| C22 | 100n | U5 decoupling |
| R26 | 10k | |
| R27, R33 | 1k | |
| R28 | 470k | |
| R29, R30 | 22k | |
| R31, R32 | 100k | |
| R34 | 330 | LED current sense |
| R35 | 100 | LED anode |
| R36 | 1M | dead zone |

LM358 pins: **1** out A, **2** −A, **3** +A, **4** GND, **5** +B, **6** −B, **7** out B, **8** V+.

## Wiring

```
DRY_OUT ─ C20 33n ─ R26 10k ─ RV1 lug 3        RV1 lug 1 ─ VB        RV1 wiper ─ U5 pin 3

U5 pin 1 ─ D5 (anode) ... D5 (cathode) ─ R27 1k ─ ENV
ENV ─ C21 1µ ─ GND
ENV ─ R28 470k ─ U5 pin 2 ─ R29 22k ─ VB
ENV ─ R30 22k ─ RV6 (as rheostat) ─ VB          DECAY

U5 pin 5 ─ ENV
U5 pin 6 ─ R31 100k ─ +9V
U5 pin 6 ─ R36 1M ─ +9V
U5 pin 6 ─ R32 100k ─ Q1 emitter
U5 pin 7 ─ R33 1k ─ Q1 base
Q1 emitter ─ R34 330 ─ GND
Q1 collector ─ vactrol LED cathode (U3 pad 2 lead)
+9V ─ R35 100 ─ vactrol LED anode (U3 pad 1 lead)

U5 pin 8 ─ +9V, pin 4 ─ GND, C22 100n across pins 8–4
```

## Taps from the board (unit 1, v1.1)

| Breadboard | Board point |
|---|---|
| +9V | C19 + or **U4 pin 8** |
| GND | any GND (C19 −, wire pad G) |
| VB | **U4 pin 7** (buffered VB) |
| DRY_OUT | **U4 pin 1** |

**Vactrol:** unsolder the **LED** leads from U3 pads 1 (anode) and 2 (cathode) and run them to the breadboard. **Leave the LDR leads on pads 3 and 4.** Keep the vactrol light-tight.

**Old LED path:** lift one end of **R7** (100 Ω). That takes the old PRE_OUT → C8 → RV1 path off the preamp, as on v1.3. The board's ENVELOPE pot (RV1 B1k) then does nothing; the breadboard pot is ENVELOPE.

## Build and check in order

Power off while wiring. Meter on DC volts, black lead on GND.

| # | Step | Expect | Measured |
|---|---|---|---|
| 1 | U5 + C22 + power only (pins 8 / 4) | pin 8 = +9V (~8.7) | |
| 2 | Add the detector (RV1, C20, R26, U5A, D5, R27, R28, R29, C21, R30, RV6). No guitar, ENVELOPE up | **ENV (C21 +) ≈ VB** (~4.4 V), within ~0.15 V | |
| 3 | Add the driver (R31, R32, R36, R33, Q1, R34) **without the LED**: leave Q1 collector open | U5 pin 7 low (≲ 1 V); V(R34) ≈ 0 | |
| 4 | Connect the vactrol LED (anode → R35, cathode → Q1 C) | **At rest: V(R34) ≈ 0 → LED off.** LED current = V(R34) / 330 | |
| 5 | Guitar in, ENVELOPE full, strum hard | ENV jumps above VB; V(R34) up to ~5 V (≈ 15 mA), LED lights, then decays | |
| 6 | Pluck **low E** then **high E**, same strength | ENV peaks roughly similar (tilt working) | |

If step 2's ENV sits well above VB: check R28/R29 (gain 22) and D5's direction. If the LED glows at rest in step 4: ENV is more than ~0.2 V above VB; check R36 (1M to +9V) and that VB really is the board's VB.

## Bonus: Trem "rush" test with the same breadboard

The same envelope + vactrol can drive the Trem's RATE (`Trem SMD/Trem Roadmap.md` § envelope-controlled RATE): move the vactrol's **LDR** to flying leads across **Trem RV1 lug 3 and wiper**, feed the breadboard's DRY_OUT input from the Trem's input (via a 1µ cap; set ENVELOPE for the Trem's lower level), and power the breadboard from the Trem's 9 V with a common GND and its own VB (two 10k from +9V to GND + 10µ).
